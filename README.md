## How I work

I run each app the way I would run a product inside a large company, at a smaller scale.

- **Written requirements first.** Every app starts from a product brief that states the problem, the bet and what is out of scope.
- **Decision logs.** Each significant choice is dated and recorded with its reason, including features cut to get through App Review.
- **Evaluation sets for AI features.** AI features are tested against fixed cases with expected answers, and the results decide what ships. Fixed safety rules run before any text reaches a model.
- **Security review of third-party tools.** I read and pin outside tools before they touch my machine or my code.
